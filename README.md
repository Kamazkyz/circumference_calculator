## Requirements

- Have a compiler like GCC (`g++`) that supports `C++17+`
- Make or CMake (optional, direct compilation via CLI is supported)
- A terminal (Bash, Zsh, PowerShell, or CMD)

## Installation & Run

Clone the repository
   ```
   git clone https://github.com/Kamazkyz/circumference_calculator.git
   cd circumference_calculator
   ```
Compile and run it with:
```
g++ -O3 main.cpp -o circumference_calculator
./circumference_calculator
```
